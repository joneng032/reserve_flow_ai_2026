# 🎨 Monokai Theme - Documentation

## 📋 **Description**

A professional dark theme based on the Monokai color scheme has been implemented, optimized for developers and with a centered and modern design.

## 🎨 **Color Palette**

### **Primary Colors**

- **Main Background:** `#272822` (Monokai Dark)
- **Secondary Background:** `#1d1e19` (Monokai Darker)
- **Tertiary Background:** `#141511` (Monokai Darkest)
- **Main Text:** `#f8f8f2` (Monokai Light)
- **Secondary Text:** `#75715e` (Monokai Gray)

### **Accent Colors**

- **Blue (Accent):** `#66d9ef` - For links and highlighted elements
- **Green (Success):** `#a6e22e` - For primary buttons and successful states
- **Yellow (Warning):** `#e6db74` - For warnings
- **Red (Error):** `#f92672` - For errors and danger buttons
- **Purple (Info):** `#ae81ff` - For additional information
- **Orange (Highlight):** `#fd971f` - For highlighted elements

### **Buttons**

```css

.btn-secondary  /* Gray with borders */
.btn-danger     /* Monokai Red */
```

### **Input Fields**

```css

```

### **Cards and Containers**

```css

```

### **States**

